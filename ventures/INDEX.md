# Venture Portfolio Index

Every venture ever explored by the studio, kept permanently — a killed venture is a successful
experiment if it saved months of work, so its record stays here as institutional memory.

Status values: `exploring` (stages 0-5), `validating` (6-8), `building` (9-10), `launched`
(11-12), `growing` (13-14), `paused`, `killed`.

## How to add a venture

1. Copy `ventures/_template/` to `ventures/<slug>/`.
2. Fill in `state.md` header fields.
3. Add a row to the table above.
4. Point `ventures/ACTIVE_VENTURE.md` at the new slug.

(`/new-venture` does all of this automatically.)
