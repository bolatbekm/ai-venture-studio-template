# Active Venture

slug: _(none — no venture is active)_

No venture has been started yet.

Run `/new-venture` to begin. The orchestrator will ask you a handful of questions, write your
answers into `founder-profile.md`, create a venture folder from `ventures/_template/`, and route
you into either problem discovery (if you have no idea yet) or validation (if you do).

## What this file is for

This is the studio's pointer to whatever is currently being worked on, and the first thing read at
the start of every session. Keep it rich rather than terse: when you return after two weeks, this
file plus `founder-profile.md` should be enough to resume without re-explaining anything.

A good entry records which venture is active and at what stage, what was decided last and why,
what is still unresolved, and — for every paused or killed venture — enough detail that you can
resume or avoid repeating it. Never delete a killed venture's folder; per CLAUDE.md §13 it stays
as institutional memory.
